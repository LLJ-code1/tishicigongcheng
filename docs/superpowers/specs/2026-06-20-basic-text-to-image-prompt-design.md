# 基础文生图提示词设计

## 目标

用户输入中文、英文或中英混合的简短描述后，系统生成：

- 可供用户阅读和修改的中文提示词。
- 可交给绘图模型执行的英文提示词。
- 中英文一一对应的结构化编辑块。
- Tags 与自然语言结合的最终提示词。

本阶段只处理“拓展已有提示词”，不处理随机生成、参考库、图像反推和专项创作。

## 采用的原文规则

### Anima Tags 无权重

采用：

- 主体和数量。
- 外观、服装、材质和配饰。
- 动作、表情和视线。
- 场景、时间和天气。
- 构图、景别和镜头角度。
- 光影、色彩和氛围。
- 英文 Tags 输出规则。

不采用：

- 成人内容细节规则。
- 强制安全等级前缀。
- 与图片反推有关的措辞。

### Anima 自然语言

采用：

- 多人角色归属。
- 前景、中景、背景位置。
- 肢体动作和物理接触关系。
- 视线方向和空间逻辑。
- 复杂构图的一至三句英文补充。

不采用：

- 随机选择题材。
- 随机选择角色或 IP。
- 成人内容概率和尺度规则。

### Prompt Assistant 通用扩写

采用：

- 保留用户明确指定的核心内容。
- 使用具体、可见的画面细节。
- 根据二次元、写实、产品、3D 等领域选择合适词汇。
- 避免跨领域术语混用。

不采用：

- 固定追加 `8K` 等通用后缀。
- 根据输入语言只输出单一语言。
- 自动加入与目标模型不匹配的摄影参数。

### Prompt Studio 现有模板

保留：

- 中英文双版本。
- 严格 JSON 输出。
- 结构化编辑块。
- 来源、置信度和锁定状态字段。

## 模块结构

基础文生图模板拆为四层：

1. `core/visual-expansion.md`
   负责忠实保留原意、补全视觉细节和检查逻辑冲突。
2. `modes/expand-hybrid.md`
   负责 Tags 与自然语言混合写法。
3. `models/<model-id>.md`
   负责目标模型的提示词格式、质量前缀和限制。
4. `schemas/bilingual-structured-output.md`
   负责中英文结构块和严格 JSON 输出。

一次模型请求按以下顺序组合：

```text
核心扩写规则
+ 混合输出模式
+ 当前模型规则
+ 双语 JSON 输出规则
+ 用户输入和可选上下文
```

## 生成流程

1. 识别输入语言，不翻译后直接扩写。
2. 提取用户明确指定的主体、动作、服装、场景、风格和限制。
3. 将缺失信息补入结构块，但不得修改用户已明确的核心设定。
4. 使用 Tags 描述画面元素。
5. 使用自然语言描述复杂动作、多人关系和空间构图。
6. 先建立统一的语义结构，再分别生成英文和中文，避免两次独立创作。
7. 检查中英文结构块是否一一对应。
8. 组合最终英文执行提示词和中文阅读提示词。

## 结构块

第一版固定使用：

- `quality`：由模型配置提供，不由 LLM 自由编造。
- `artist`：由用户或资源库提供，默认留空。
- `subject`：主体、数量、角色身份。
- `appearance`：外观、发型、服装、材质和配饰。
- `pose`：动作、姿态、表情、视线和互动。
- `scene`：场景、环境、时间和天气。
- `composition`：景别、角度、位置和空间关系。
- `lighting`：光源、色彩、明暗和氛围。
- `effects`：道具、粒子、天气效果和视觉特效。
- `negative`：由模型配置和用户限制组成。

## 输出格式

```json
{
  "positiveEn": "",
  "positiveZh": "",
  "negativeEn": "",
  "negativeZh": "",
  "relationEn": "",
  "relationZh": "",
  "blocks": [
    {
      "id": "subject",
      "label": "主体与角色",
      "en": "",
      "zh": "",
      "weight": 100,
      "locked": false,
      "source": "user|expanded|resource|model_profile",
      "confidence": 90
    }
  ],
  "checks": {
    "preservedUserIntent": true,
    "bilingualAligned": true,
    "conflicts": [],
    "assumptions": []
  }
}
```

`positiveEn` 的组合顺序为：

```text
模型质量前缀 + 结构块英文 Tags + relationEn
```

`positiveZh` 使用相同结构的中文内容，仅用于阅读、修改和存档。

## 模型差异

基础扩写规则保持通用，模型差异放入独立 Model Profile：

- Anima / WAI-ANIMA：Tags 与简短英文自然语言混合。
- Stable Diffusion：可选择纯 Tags 或带权重 Tags。
- 其他模型：后续新增独立配置，不修改核心扩写规则。

第一版默认目标为 Anima，默认不使用文本权重。

## 编辑和再次生成

- 用户修改任一结构块后，系统重新组合最终提示词。
- 锁定的结构块不得被整段重新生成覆盖。
- 单块再生成时，只把该块、锁定块和必要上下文发送给 LLM。
- 应用结果时保存为新版本，不覆盖旧版本。

## 错误处理

- JSON 解析失败：自动要求模型只修复格式，不重新创作内容。
- 中英文缺失：根据已有结构补齐缺失语言。
- 用户输入与扩写冲突：保留用户输入，并在 `checks.conflicts` 记录冲突。
- 模型加入未要求的角色、IP 或画师：删除该内容并记录为假设错误。

## 测试标准

至少使用以下输入测试：

- `1girl, raining`
- `一个黑发女孩站在雨中的城市街道`
- `1girl，黑色长发，looking back，雨夜`
- 双人互动和前后景关系。
- 用户锁定服装后重新生成动作。

每个测试必须验证：

- 中英文含义对应。
- 用户明确内容未被修改。
- 输出 JSON 可解析。
- 结构块完整。
- 英文最终提示词符合 Anima 混合格式。
- 默认没有自动加入画师、角色 IP 和文字权重。

## 暂不包含

- 成人向模板。
- 全随机提示词。
- 参考提示词库。
- 图像反推。
- 巨构和古风等专项模板。
- LoRA、采样器和 ComfyUI 执行参数。
