# 保真提示词拆解设计

## 目标

在文生图“拓展”输入区新增“仅拆解”入口。用户粘贴完整中文、英文或混合提示词后，系统只进行分类和双语对应，不补充、不删减、不润色原始内容。现有“拓展并结构化”流程保持不变。

## 交互

- 输入框下方并列提供“仅拆解”和“拓展并结构化”。
- “仅拆解”调用当前选中的本地 LLM 或外部 API。
- 成功后进入现有结构化编辑器，生成版本 1。
- 原始片段按主体、外观、动作、场景、构图、光影、特效、画师、质量、负面词分类。
- 无法可靠分类的片段进入“其他 / 未分类”。
- 用户随后可以手工编辑、锁定或对支持的结构块执行“随机变体”。

## 保真规则

- 服务端以用户输入切分出的原始片段为权威来源。
- 模型必须逐项返回原始片段、英文表达和中文表达。
- 服务端把模型返回的原始片段重新映射为用户输入中的精确文本，避免模型偷偷改写。
- 每个原始片段必须且只能出现一次；缺失、重复或凭空新增时拒绝整个结果。
- 中文片段必须原样保存在中文结构块，英文片段必须原样保存在英文结构块；另一语言由模型翻译。
- 校验失败时不更新结构化编辑器，输入框内容继续保留。

## 边界

- 不修改现有 `/api/text/expand`、扩写提示词模板、扩写强度和前端扩写动作。
- “仅拆解”不注入 Anima 默认质量词或负面词。
- “仅拆解”不执行内容密度检查，因为完整输入允许某些结构块为空。

## 测试

- 单元测试覆盖纯英文、纯中文、混合输入、未分类内容和覆盖校验失败。
- 服务端测试确认新接口使用保存的模型配置且不影响原扩写接口。
- 前端测试确认两个按钮同时存在，拆解状态与扩写状态共享结构化结果但使用不同动作。
