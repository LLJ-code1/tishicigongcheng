# Anima Prompt Studio 第一阶段设计

## 1. 产品定位

Anima Prompt Studio 是一个本地优先的 AI 绘图提示词工作台。它整合：

- Anima Prompt Editor v2 的结构化提示词编辑能力；
- 37PromptHub 的提示词案例库、分类、搜索和轻量入口；
- Anima Style Explorer 的画师检索、预览和选择能力；
- WD14、Florence PromptGen、JoyCaption、QwenVL 等本地图片识别模型；
- 本地 LLM 与外部 API 两类文本和视觉推理来源。

第一阶段只处理提示词和图片解析，不接入 ComfyUI 出图，不提供采样器、步数、重绘幅度或工作流发送功能。

## 2. 首页

应用启动后默认进入“新建作品”，不打开最近项目，也不使用宣传型首页。

首屏提供两个主要入口：

1. 文生图
2. 图片解析

首屏同时提供参考提示词库、角色库、画师库和设置的次级入口，并显示本地模型服务与外部 API 的连接状态。

## 3. 文生图

文生图包含三个模式。

### 3.1 全随机

系统从人物、服装、动作、表情、场景、构图、光影、特效、风格和画师等槽位随机组合内容。随机结果进入统一结构化编辑器，允许用户继续修改。

随机过程可以在后台记录技术种子和实际抽中的词条，用于历史复现，但前台不显示或要求用户填写随机种子。用户操作只包括“再来一组”和锁定人物、画师、场景等指定部分。保存作品时保存实际 SceneSpec 和抽取记录，不依赖用户记住种子。

### 3.2 拓展提示词

用户可输入中文、英文或中英混合内容。系统自动识别输入语言，在保留原始意图的前提下补充细节并规范提示词结构。

例如，输入 `1girl, raining` 后，可补充人物外观、动作、雨景、构图、镜头、光影、氛围和画质信息。

### 3.3 参考提示词库

参考库由用户长期维护。每条案例可包含：

- 示例图片；
- 中文提示词；
- 英文提示词；
- 中文与英文负面提示词；
- 来源；
- 标签和分类；
- 适用模型；
- 用户备注。

案例支持浏览、搜索、筛选、复制和“一键带入拓展提示词”。带入后，案例内容成为当前新作品的初始素材，不修改原始案例。

### 3.4 文生图推理来源

每次文生图任务都可以在输入区直接选择：

- 本地 LLM；
- 外部文本 API。

选择只影响当前生成、扩写、翻译和结构化任务。系统设置保存默认来源。全随机的基础槽位抽取由本地词库完成，LLM 或 API 负责补全、整理和双语输出。

## 4. 图片解析

图片解析用于从上传图片中恢复标签、画面描述和结构化提示词。

用户可以勾选一个或多个识别器：

- WD14：提供适合动漫和 Anima 体系的 Danbooru 标签及置信度；
- Florence PromptGen：提供接近 AI 绘图提示词的标签和描述；
- JoyCaption：提供较完整的自然语言画面描述；
- QwenVL：按人物、场景、构图、光影等要求做深度结构化分析；
- 外部视觉 API：作为可选的在线分析来源。

默认“自动组合”使用 WD14、Florence PromptGen 和文本 LLM：

1. WD14 提取标签和置信度；
2. Florence 生成绘图描述；
3. 文本 LLM 合并结果、处理重复和冲突；
4. 生成统一的 SceneSpec；
5. 输出中英文提示词。

界面必须保留每个识别器的原始结果，不能只显示合并后的文本，以便用户判断错误来自哪个模型。

## 5. 结构化编辑器

Anima Prompt Editor v2 作为核心编辑器，但结构块扩展为：

- 质量与元数据；
- 画师与风格；
- 主体与角色；
- 外观与服装；
- 动作与表情；
- 场景；
- 特效与道具；
- 构图与镜头；
- 光影与氛围；
- 负面提示词。

每个结构块支持：

- 编辑中文或英文内容；
- 调整重要度；
- 锁定，防止后续重写改变；
- 删除；
- 单块重新生成；
- 查看来源和置信度。

结构块编辑采用“草稿修改”逻辑。用户直接修改动作、服装、角色等内容时，右侧最终 Prompt 不立即变化；被修改的块显示未应用状态。底部提供：

- 撤销未应用修改；
- 应用修改并生成新版本。

应用后系统更新 SceneSpec、同步另一语言、按目标 ModelProfile 重新编译正负提示词，并保存为 `V2`、`V3` 等版本。锁定块不允许被 AI 重写。

编辑器右侧始终显示：

- 英文正向提示词；
- 中文正向提示词；
- 英文负面提示词；
- 中文负面提示词。

这里的“双版本”指同一提示词内容的中英文对应版本，不是两套不同创意。

## 6. 推理来源

文本处理和图片处理都提供来源选择。

### 6.1 文本推理

- 本地 LLM；
- 外部文本 API。

用于扩写、翻译、结构化、冲突处理和最终提示词重写。

### 6.2 图片推理

- 独立本地图片识别服务；
- 外部视觉 API。

本地图片识别模型不依赖 ComfyUI。网页通过仅监听 `127.0.0.1` 的本地服务调用模型。

## 7. 本地模型管理

网页不直接加载 Python 模型。独立本地模型管理器负责模型下载位置、加载、推理、排队、显存释放和状态上报。

默认生命周期策略为“智能驻留”：

1. 应用启动时不加载视觉模型；
2. 用户开始分析后，按顺序加载所选模型；
3. 大型模型默认串行运行，避免同时占满显存；
4. 任务结束后保留最近使用的模型五分钟；
5. 五分钟内再次调用时直接复用；
6. 超时后自动卸载并清理显存；
7. 用户可以随时点击“立即释放”；
8. WD14 可配置为 CPU 常驻，其他大型模型默认临时驻留。

设置中提供三种策略：

- 智能驻留：默认，空闲五分钟后释放；
- 用完即释放：节省显存，但连续任务较慢；
- 始终保持加载：连续任务最快，占用资源最多。

界面显示每个模型的状态：未加载、加载中、已就绪、运行中、等待中、释放中和错误。

## 8. 数据模型

系统使用版本化的 SceneSpec 作为统一中间结构。文生图、参考库案例和图片解析最终都转换为 SceneSpec，再由模型适配器生成提示词。

核心对象包括：

- `ProjectDraft`：当前新作品和编辑状态；
- `SceneSpec`：与目标绘图模型无关的画面事实；
- `ModelProfile`：Anima、WAI-ANIMA 等提示词规范；
- `ReferenceEntry`：参考图片与双语提示词案例；
- `AnalysisRun`：一次图片分析中各识别器的原始结果；
- `PromptResult`：中英文正负提示词、警告和来源记录。
- `ProjectVersion`：一次已应用的 SceneSpec、PromptResult、修改来源和版本号；
- `ReusableResource`：用户长期维护的角色、服装、动作、场景、画师或提示词片段。

## 8.1 长期快速资源

快速资源允许用户新建、编辑和删除。资源可以从三个入口产生：

- 资源库中的“新建资源”；
- 结构块中的“保存为资源”；
- 参考案例或图片解析结果中的“提取为资源”。

资源带入当前作品时只复制内容，不修改资源本身。带入后的内容作为未应用修改进入对应结构块，用户确认“应用修改并生成新版本”后才更新最终 Prompt。

## 9. 静态展示版

第一版 HTML 是可点击的产品原型，不调用真实模型。它应展示：

- 新建作品首页；
- 文生图与图片解析入口；
- 全随机、拓展提示词和参考库标签页；
- 参考案例一键带入拓展区；
- 图片上传区域与识别模型多选；
- 自动组合开关；
- 模型队列、运行状态和立即释放按钮；
- 结构化编辑块；
- 中英文正负提示词汇总；
- 角色库和画师库入口；
- 文生图本地 LLM / 外部 API 的按次选择；
- 长期资源的新建和带入；
- 未应用修改提示、撤销和“应用修改并生成新版本”；
- `V1`、`V2` 等版本状态；
- 本地 LLM、外部 API 与模型驻留设置。

所有关键按钮应有模拟交互，让用户能够评估页面层级和操作流，而不仅是查看静态截图。

展示版仅针对 Windows 桌面端 `1920×1080` 设计和验收，不包含手机端导航或移动布局。

## 10. 错误处理

- 本地服务未启动时，显示明确的连接状态和启动提示；
- 单个识别模型失败时，保留其他模型结果并允许单独重试；
- 显存不足时，建议释放模型或切换串行模式；
- 外部 API 不可用时，允许切换本地来源；
- 中英文同步失败时，保留原文并标记另一语言待刷新；
- LLM 输出不符合 SceneSpec 时，执行有限次数的修复重试并保留原始响应。

## 11. 第一阶段验收

- 首页默认进入新建作品；
- 中文、英文和混合输入均可进入拓展流程；
- 每次结果都有对应的中英文正负提示词；
- 参考案例可一键带入且不会修改原案例；
- 全随机界面不要求用户理解或填写随机种子；
- 文生图任务可以按次切换本地 LLM 或外部 API；
- 快速资源可以长期新建并带入对应结构块；
- 修改结构块不会立即覆盖最终 Prompt，应用后生成新版本；
- 图片解析可自由选择多个本地或外部识别器；
- 自动组合保留各模型原始结果和合并结果；
- 模型驻留状态和释放操作清晰可见；
- 所有核心流程能在静态 HTML 展示版中完成模拟操作；
- 第一阶段界面不出现 ComfyUI 出图参数和生成工作流。
