# 模型驱动全随机提示词设计

日期：2026-06-22

## 目标

将文生图“全随机”从前端两条写死示例改为真实模型任务。点击后使用当前选择的本地 LLM 或外部 API，生成适用于 Anima 的高密度中英文结构化提示词。

## 生成流程

1. 模型先生成一份完整随机画面蓝图，包括主体、外观服饰、动作关系、场景、构图、镜头、光影、色彩、特效与道具。
2. 模型再根据蓝图和现有 Anima 规则编译十个标准结构块。
3. 输出英文正向、中文正向、英文负面、中文负面及中英文关系描述。
4. 内容密度按创意模式校验，至少包含 35 个有效视觉细节。
5. 结构或密度不合格时允许修复重试一次。

## 行为

- 不要求用户先输入内容。
- 使用当前文本来源设置；选择外部 API 时必须真实调用外部模型。
- 全随机固定采用高细节创意规则，不受严格、均衡、创意切换影响。
- 不再保留静态示例作为成功兜底；模型失败时明确显示失败。
- 生成过程使用现有进度面板，显示蓝图设计和提示词编译阶段。

## 验收

- 前端点击全随机会请求 `/api/text/random`。
- 后端依次完成蓝图与完整提示词调用。
- 结果包含十个结构块和中英文版本。
- 英文正向提示词至少达到创意模式的内容密度要求。
- 使用当前 DeepSeek 外部 API 完成一次真实端到端成功测试。
- Python 与 Node 全量测试通过。
