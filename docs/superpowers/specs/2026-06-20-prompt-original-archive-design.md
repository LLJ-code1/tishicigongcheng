# 提示词原文归档设计

## 目标

从 `G:\新建文件夹` 中提取所有用于指导 LLM 执行任务的提示词框架，保存到项目内的独立目录，供人工逐条查看。

## 范围

本次只归档提示词框架原文：

- ComfyUI 工作流节点中的长指令文本
- `Anima巨构提示词.txt`
- Prompt Assistant 的系统提示词
- Prompt Assistant 的 Kontext 图像编辑提示词片段
- Danbooru Gallery 的角色特征替换提示词
- Prompt Gallery 的筛查代码生成提示词

本次不归档成品绘图提示词、质量词、负面词、角色词、画师词、LoRA 配方和采样参数。

## 输出结构

输出目录为 `提示词原文归档`，包含：

- `去重阅读版`：相同原文只保留一份，按来源和安全属性分类。
- `按来源完整副本`：每个工作流节点和插件配置项都单独保留，重复内容也不省略。
- `manifest.json`：记录文件、来源、节点标题、原文哈希和重复关系。
- `README.md`：说明统计数字、目录用途和筛选边界。

## 原文原则

- 不润色、不翻译、不纠错。
- JSON 转义字符按运行时文本还原，不改变语义。
- 文件正文只写原始提示词，不插入说明文字。
- 来源和分类信息写入文件名及清单，不混入正文。
- 成人向或支持混合尺度生成的框架独立归类，不与普通框架混放。

## 验证

- 提取脚本使用测试样例验证去重、来源映射和正文不变。
- 对真实来源运行后重新读取全部输出文件，核对 SHA-256。
- 输出统计必须同时给出去重数量和来源实例数量。
