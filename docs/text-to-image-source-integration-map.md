# 文生图原文整合与冲突裁决

## 目标

本文件用于把“提示词原文归档”中的文生图规则整理为可组合的 LLM 系统提示词。整合不是把所有原文直接拼接，而是提取有效规则、标记来源、解决冲突，并按运行模式加载。

当前 `prototype/prompts/text/` 下的四个简化模块只作为调用链骨架，不代表最终整合结果。

## 原文分流

### 直接进入文生图母版

| 原文类别 | 主要贡献 | 进入模块 |
| --- | --- | --- |
| 扩写-通用 | 输入保真、内容扩写、物理细节、场景与构图 | 核心扩写 |
| 扩写-人像大师 | 人像题材判断、皮肤与材质、五官微表情、服饰、光影 | 人像领域包 |
| 扩写-Tags 风格 | 标签化表达、标签顺序、去重、单行输出 | Tags 编译器 |
| Anima 英文 Tags 无权重 | 主体、动作、多人关系、环境、光影、构图 | Anima Tags 模式 |
| Anima 英文 Tags 带权重 | 权重分配原则 | 可选权重模式 |
| Anima 英文自然语言 | 空间关系、肢体逻辑、画面叙事 | 自然语言模式 |
| 随机 SAFE 提示词 | 随机题材池、变量维度、多样性与历史避重 | 全随机模式 |
| 古风系列 | 古风人物、服装、建筑、远景和场景特化 | 古风领域包 |

### 仅供图片解析或图生图使用

- ImageCaptionNode、Caption-Tags、Detail Caption。
- 反推英文 Tags、反推英文句子、像素级描述、图像描述-Tag 风格。
- Kontext 与 Qwen-Image-Edit 指令优化。
- 29 个 Kontext 图像编辑预设。
- 图像编辑重绘。

这些原文不能混入基础文生图系统提示词，否则会让没有参考图的任务误用“保持原图”“只修改局部”等规则。

### 独立功能模块

- 视频提示词、视频分镜、视频复刻：后续视频方向。
- 图库筛查项代码生成器：图库管理工具。
- 标签提取与标题生成：作品保存和自动命名。
- 成人向、擦边和 NSFW 随机规则：独立内容配置，不进入默认基础模式。

## 必须吸收的能力

### 1. 输入解析与保真

- 识别中文、英文和中英混合输入。
- 提取用户明确给出的主体、数量、身份、IP、外观、服装、动作、表情、场景、时间、天气、构图、光影、风格、排除项。
- 明确内容不可删除、替换或弱化。
- 把用户原始内容、资源注入内容和模型补充内容分开记录。

### 2. 模式路由

- 全随机：自主生成完整题材，并根据历史结果避重。
- 拓展提示词：围绕用户已有内容补全，不改变核心意图。
- 参考提示词：保留参考结构或风格规律，但不照抄参考内容。
- 局部再生成：只重写指定结构块，遵守其他块的锁定内容。

### 3. 题材识别

- 人像、角色插画、场景、古风、巨构、产品、写实摄影、3D、平面设计等题材使用不同细节清单。
- 题材专用规则作为领域包按需加载，不能把所有题材术语同时塞进结果。

### 4. 主体与角色

- 明确主体类型、数量、年龄层、体态和身份。
- 已知角色只在用户明确输入或角色库注入时使用。
- 多人场景为每个角色建立独立属性，避免发型、服装和动作串位。
- 角色库内容优先于模型自行猜测的角色特征。

### 5. 外貌、服装与材质

- 发型、发色、瞳色、体态、服装层次、材质、配饰、纹理和衣物状态。
- 服装和环境、天气、动作之间必须相容。
- 人像领域可以增加皮肤与细微质感；二次元模式不得强行加入写实摄影词。

### 6. 动作、表情与互动

- 面部：视线、眉、眼、嘴和微表情。
- 肢体：头、躯干、左右臂、左右手、左右腿、脚和重心。
- 接触动作写清发起者、承受者和接触部位。
- 非接触互动写清视线、距离、朝向和空间张力。
- 检查肢体位置、重心和因果关系是否可实现。

### 7. 场景与空间

- 场景类型、空间布局、环境元素、前中后景、时间和天气。
- 环境元素必须服务于主体和题材，不能无目的堆砌。
- 巨构模式必须强调建筑外部、极远景和尺度参照；不能误生成室内。

### 8. 构图与镜头

- 景别、镜头角度、主体占比、画面位置、视线方向和视觉焦点。
- 构图词必须与场景规模、人物数量和动作一致。
- 只有用户要求或题材需要时才加入具体焦段、相机和摄影参数。

### 9. 光影与色彩

- 光源类型、方向、软硬、色温、主辅光关系、阴影、轮廓光和环境反射。
- 主色调、辅助色、冷暖关系和明暗对比必须互相协调。
- 避免同时出现互相冲突的时间、天气和光源。

### 10. 输出编译

- Tags：负责可拆分的主体、外观、服装、基础动作、场景、构图、光影和效果。
- 自然语言：负责复杂动作、多人互动、空间关系和因果关系。
- 默认使用 Tags + 短自然语言混合模式。
- 中英文是同一份结构的两种表达，不允许分别创作。
- 英文应使用模型可理解的标签和短句，中文用于准确编辑，不做生硬逐词翻译。

### 11. 质量检查

- 检查遗漏、重复、冲突、属性串位、肢体不可能、空间关系不清、光源矛盾和中英文不一致。
- 每项模型补充内容记录为“AI 补充项”，供用户保留、删除或重新生成。
- 输出前进行去重和顺序整理，不把检查过程写进最终绘图提示词。

## 冲突裁决

| 原文冲突 | 最终规则 |
| --- | --- |
| 跟随输入语言 vs 需要中英文双版本 | 始终输出中英文双版本 |
| 纯 Tags vs 纯自然语言 | 设为可选输出模式，默认混合模式 |
| 强制权重 vs 禁止权重 | 默认无文字权重；权重交给结构编辑器；保留可选导出模式 |
| 自动使用已知 IP 角色 vs 不擅自加角色 | 只有用户输入或角色库注入时使用 IP 角色 |
| 自动随机题材 vs 忠实扩写 | 仅全随机模式自动选题；拓展模式必须忠实输入 |
| 写实摄影术语 vs 仅二次元 | 根据目标模型和题材路由，不跨领域混用 |
| 8K、masterpiece 等固定质量词 vs 禁止空泛质量词 | 由模型配置单独注入，内容扩写器不自行添加 |
| 大量示例引导 vs 避免模仿 | 示例只用于抽取结构，不进入运行时母版 |
| 成人规则与默认安全规则 | 内容配置隔离，默认基础模式不加载成人模块 |
| 每个名词强制两个修饰词 vs 避免堆砌 | 改为扩写强度控制，不机械修饰每个名词 |

## 最终运行时结构

LLM 系统提示词按任务动态组合：

1. 总控制器：角色、优先级、输入保真、禁止事项。
2. 任务模式：全随机、拓展、参考或局部再生成。
3. 目标模型：Anima 质量词、标签习惯和禁用项。
4. 输出风格：Tags、自然语言或混合。
5. 领域包：人像、古风、巨构等按需选择。
6. 资源上下文：用户选择的角色、画师和个人素材。
7. 双语结构：结构块、来源、锁定状态和 AI 补充项。
8. 自检器：逻辑、冲突、去重和中英文一致性。

不会把不相关的图片编辑、反推和视频规则加入文生图请求。
