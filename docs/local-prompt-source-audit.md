## 2. 提示词规则文本

文件：

```text
提示词规则\Anima巨构提示词.txt
```

该文件包含两套高度专用的巨构提示词规则：

1. 有动物或微小主体版本。
2. 无动物、纯巨构场景版本。

### 2.1 共同核心

- 主题是巨构、砼核、粗野主义、重工业、悬浮都市、深渊遗迹、东方巨型建筑等。
- 必须表现建筑外部，不允许生成室内、天花板或全封闭隧道。
- 构图以极远景、超广角、全景为主。
- 必须尽量展示建筑至少一半以上的外部体量。
- 通过云层、山脉、地形或微小主体建立尺度对比。
- 强调大气透视、体积光、深邃阴影、压迫感和纪念碑感。

### 2.2 有主体版本

结构顺序：

1. 极限镜头。
2. 巨型建筑外部。
3. 极微小主体。
4. 光影与氛围。

微小主体可以是人物、鹿、鸟、机器人等，要求主体占画面比例极低，并使用 `microscopic`、`tiny speck`、`dwarfed by` 等尺度词。

### 2.3 无主体版本

结构顺序：

1. 极限镜头。
2. 巨型建筑外部。
3. 光影与氛围。

明确禁止人物、动物和幻想生物。

### 2.4 输出风格

- 只输出英文自然语言段落。
- 不输出解释。
- 不使用逗号标签堆叠。
- 禁用 `8k`、`masterpiece`、`by artist` 等质量或画师标签。
- 依靠物理细节、镜头和空间尺度建立画面质感。

结论：这套规则不适合直接合并到全局文生图模板，应作为两个独立创作预设：

- `megastructure_with_subject`
- `megastructure_environment_only`

## 3. Anima 工作流

### 3.1 基础模型组合

多个工作流共同使用：

- Anima 基础模型：`anima-base-v1.0`
- 文本编码器：`qwen_3_06b_base.safetensors`
- VAE：`qwen_image_vae.safetensors`
- 常用放大模型：`RealESRGAN_x4plus_anime_6B.pth`

部分图生图工作流还包含：

- Anima LLLite
- SAM 3.1 分割模型
- WD14 标签识别

### 3.2 基础质量词

多数工作流使用类似的正向前缀：

```text
year 2023, year 2024, year 2025, highres, masterpiece,
best quality, score_7, score_8, score_9
```

常见负面词：

```text
worst quality, low quality, score_1, score_2, score_3,
blurry, jpeg artifacts, sepia, watermark
```

部分工作流额外排除审查条、马赛克、错误手部、文字和签名。

这些内容应归入“模型配置/质量预设”，不应写死在全局系统提示词里。

### 3.3 文生图版

`Anima伊曦工作流（文生图版）.json` 包含：

- 中文、英文和混合内容输入。
- 标签型和自然语言型两种输出。
- 提示词提纯、丰富和优化。
- 安全标签分类。
- 画师库随机选择。
- LoRA 配方切换。
- 标题摘要生成。
- 提示词历史或分类读取。

其提示词结构主要覆盖：

1. 主体与数量。
2. 外观、体型、发色、瞳色、发型。
3. 服装、材质、穿着状态。
4. 动作、姿势、表情和视线。
5. 场景、时间、天气。
6. 构图、镜头和景别。
7. 光影、色彩和氛围。
8. 画师或视觉风格。

这与当前 Prompt Studio 的结构块高度一致，可作为文生图模板改造来源。

### 3.4 图生图版

`Anima伊曦工作流（图生图版）.json` 包含多种图片反推路径：

- 外部视觉 API 直接反推。
- WD14 直接反推标签。
- WD14 标签与原图共同交给视觉模型合并。
- 图片与 Danbooru 相关资源结合分析。
- 标签输出和自然语言输出两种格式。
- 反推结果再次扩写、提纯和合并。

该工作流的重要经验是：保留原始 WD14 标签，再由视觉模型或 LLM 生成自然语言版本，不能只保留最终合并文本。

### 3.5 随机提示词规则

多个工作流带有随机提示词生成器，主要能力包括：

- 随机题材。
- 避免与最近使用题材重复。
- SFW 和成人向规则分流。
- 自然语言和标签形式分流。
- 自动生成不超过约 20 个汉字的提示词标题。
- 将人物、动作、场景、构图、光影和风格串成一幅具有故事感的画面。

源工作流包含成人向生成规则。导入 Prompt Studio 时必须与默认模板隔离，不应默认启用，也不能与未成年角色描述混合。

### 3.6 LoRA 画风配方

`lora堆画风工作流` 包含六套主要配方：

| 文件 | 主要方向 |
| --- | --- |
| `叶anima画风一3d.json` | 3D、半写实皮肤、立体光照 |
| `叶anima画风二.json` | 精致半写实、场景增强、WLOP 类氛围 |
| `叶anima画风三.json` | 场景细节、光影、动画截图与综合风格 |
| `叶anima画风四.json` | 动画截图、粗线条、场景增强和偏敏感内容规则 |
| `叶anima画风五.json` | 绘画感、混合风格、复杂场景 |
| `叶anima画风五（场景特化）.json` | 画风五的场景强化版本 |

LoRA 名称、权重和触发词应整理成独立的 `StyleRecipe`，不能混入文本模型系统提示词。

### 3.7 二次采样与放大

- `风若离anima二采.json`：使用高分、美学、Turbo 等 LoRA 进行二采。
- `咕咕嘎嘎anima TTP放大流.json`：包含多批次、WD14、放大和不同降噪强度。

这两类属于未来 ComfyUI 出图阶段，当前不接入 Prompt Studio 第一阶段。

### 3.8 样图

共有 167 张 PNG，约占本目录大部分体积。

扫描结果：

- PNG 中没有发现标准 ComfyUI `prompt` 或 `workflow` 文本元数据。
- 这些图片适合作为画风配方预览图。
- 提示词和参数仍需从对应 JSON 工作流提取，不能只靠 PNG 自动恢复。

## 4. 插件梳理

### 4.1 高优先级参考

#### Anima Style Explorer

- Anima 2B 画师风格可视化数据库。
- 支持预览和收藏。
- 与当前 AnimaDex 角色/画师资源方向相近。

建议：保留为画师风格预览参考，不直接依赖其在线服务。

#### ComfyUI Prompt Manager

- 分级分类。
- 角色、画师、场景、光影等 Prompt 预设。
- 收藏。
- 本地/云端图库。

建议：重点参考其分类、收藏和导入逻辑。

#### ComfyUI Prompt Gallery

- 提示词图库。
- 封面图。
- 分类和组合。
- 随机/循环抽取。
- Prompt 权重和格式模板。

建议：重点参考“参考提示词库”和“我的素材”。

#### ComfyUI Prompt Assistant

- 标签编辑和提示词辅助。

建议：参考标签选择、翻译和编辑体验，不直接照搬 ComfyUI 节点界面。

#### ComfyUI Danbooru Gallery

- Danbooru 图片检索。
- 提示词清洗。
- 角色特征交换。
- 多角色编辑。

建议：后续图生图和参考库阶段评估，当前不直接接入。

### 4.2 中优先级参考

#### ComfyUI LoRA Manager

- LoRA 文件管理。
- 配方管理。
- 模型和工作流联动。

建议：未来建立本地 LoRA 资源库时参考。第一阶段只保存 StyleRecipe 元数据。

### 4.3 当前不接入

#### Comfy-WaveSpeed

ComfyUI 推理加速插件，与当前提示词生成阶段无直接关系。

#### ComfyUI Anima LLLite

Anima 的轻量 ControlNet/LLLite 节点，属于未来图生图和 ComfyUI 出图阶段。

## 5. 建议导入 Prompt Studio 的内容

### 5.1 提示词模板

建议新增独立模板：

- `text_expand_tags`
- `text_expand_natural_language`
- `text_random_anime`
- `image_reverse_tags`
- `image_reverse_natural_language`
- `image_reverse_merge`
- `megastructure_with_subject`
- `megastructure_environment_only`
- `prompt_title_summary`

### 5.2 模型配置

单独保存：

- 质量词前缀。
- 负面词预设。
- Anima / WAI-ANIMA 模型差异。
- 标签型或自然语言型输出偏好。

### 5.3 StyleRecipe

单独保存：

- 配方名称。
- LoRA 名称。
- 权重。
- 触发词。
- 适用模型。
- 预览图目录。
- 推荐采样参数。

### 5.4 不应直接导入的内容

- ComfyUI 节点位置和连线。
- KSampler、放大、二采等出图参数。
- 重复的完整工作流 JSON。
- 默认成人向随机规则。
- 与提示词无关的加速插件代码。

## 6. 推荐实施顺序

1. 从伊曦文生图工作流提炼“标签扩写”和“自然语言扩写”模板。
2. 从伊曦图生图工作流提炼“WD14 + 视觉模型 + LLM 合并”模板。
3. 将巨构规则拆成两个独立创作预设。
4. 将质量词和负面词整理为 Anima ModelProfile。
5. 将六套 LoRA 工作流整理为 StyleRecipe，不接 ComfyUI。
6. 将 167 张样图按配方目录作为 StyleRecipe 预览图。
7. 成人向规则保持单独隔离，不进入默认模板。
