# Anima Prompt Studio 验收标准

> 适用范围：个人本地工作台第一阶段
>
> 相关文档：[产品需求文档](product-requirements.md) · [分阶段实施计划](implementation-plan.md)

## 1. 总体验收口径

产品通过验收，需要同时满足功能正确、结果可用、数据可恢复和边界真实四类条件。

最重要的人工结果指标是：将系统输出复制到 Anima 后，通常能在 1–2 轮手动出图内稳定接近创意，主体、画风和构图基本正确，且不是偶然抽卡撞出。

由于当前没有用户指定的代表性真实案例，第一轮开发暂用仓库已有的“悬浮女魔法师释放冲击波”复杂场景作为文字链路回归案例；正式验收前应再补充至少一个用户日常使用的真实文字案例和一个参考图片案例。

## 2. 验收环境与固定条件

- Windows 本地环境运行 Prompt Studio。
- 使用固定版本的 Anima_1.1 档案和已登记 LoRA。
- 每个对比案例固定 Seed；需要评估稳定性时另用预先记录的一组 Seed。
- 记录正向/负向提示词、模型、LoRA、参数、应用的修改指令和最终结果。
- 外部出图由用户手动完成，不把 ComfyUI 自动化作为通过条件。
- 不使用自动生成结果评分代替用户判断。

## 3. 主链路验收

### AC-01 模糊中文创意

给定一段不完整但方向明确的中文创意：

- 系统保留主体、题材和情绪方向。
- 自动补足构图、镜头、环境和光影等低风险内容。
- 不擅自加入会改变题材的关键人物、事件或情绪。
- 重大歧义最多给出少量清晰候选，不进入连续盘问。
- 生成完整 Anima 配方，而不只有单段提示词。

### AC-02 参考图片

给定一张没有原始提示词和元数据的普通图片或 AI 图片：

- 系统仅根据可见像素提取主体、人物特征、服装、动作、构图、镜头、环境、光影和画风。
- 看不清的内容进入“不确定”，不写成确定事实。
- 有冲突结论需要用户确认。
- 每条融合结论可以展开查看来源模型和原始输出。

### AC-03 图片加文字覆盖

给定参考图和“保留姿势与构图，只替换服装和夜景环境”等指令：

- 服装和环境被标记为可修改。
- 姿势和构图被标记并实际锁定。
- 其他未点名的可见属性尽量保留。
- 执行前可以看到覆盖范围。

### AC-04 完整配方复制

- 正向提示词、负向提示词、模型、LoRA、触发词、权重和基础参数都可单独复制。
- 一键复制摘要包含全部必需字段。
- 复制内容与当前界面和已保存版本一致。
- 默认前缀不包含 `safe`。

## 4. 中文局部修改验收

### AC-05 只改服装

执行“只改服装”为指定新服装：

- 预览只命中服装与配饰结构块。
- 人物身份、外观、表情、动作、互动、构图、场景、光影和风格保持不变。
- 用户确认后生成新版本。

### AC-06 人物不变，换成俯拍

- 预览命中构图与镜头结构块。
- 人物身份、外观、服装和动作被锁定。
- 如果俯拍与原动作存在不可兼容处，系统明确列出冲突，不静默重写人物动作。

### AC-07 保留构图，加强夜景氛围

- 原构图和镜头语义保持不变。
- 只调整环境、光影与色彩中和夜景有关的内容。
- 前后差异可被逐块核对。

### AC-08 撤销与追溯

- 每次应用修改都能查看指令原文、受影响块和前后值。
- 撤销后完整配方恢复到修改前状态。
- 刷新页面并重新打开项目后，历史仍存在。

## 5. 模型、参数与 LoRA 验收

### AC-09 参数优先级

构造模型默认、LoRA 要求、任务预设和手动覆盖互相不同的测试数据：

- 最终结果严格遵循“手动覆盖 > 任务预设 > LoRA 兼容要求 > 模型默认”。
- 每个参数显示最终来源。
- 任何覆盖都不得静默发生。

### AC-10 Anima_1.1 档案

- 档案绑定精确版本 ID `3004063`。
- 初始默认值与产品需求文档一致，并标明验证状态。
- 用户可以编辑档案，但修改会产生审计记录。
- 未验证尺寸不会进入自动推荐。

### AC-11 LoRA 目录扫描

- 可以配置多个目录并增量发现新增文件。
- 扫描前后原文件路径、名称、内容和时间戳不因系统操作而改变。
- 文件删除或目录离线后只标记缺失，历史配方仍保留。
- 文件恢复到不同路径后可通过哈希重新关联。
- 仅凭文件名得到的信息必须标为候选。

### AC-12 LoRA 推荐

- 与基础模型版本不兼容的 LoRA 不进入默认候选。
- 同类型重叠 LoRA 默认只推荐一个主项并说明原因。
- 互补组合必须说明每个 LoRA 的职责。
- 推荐包含触发词、权重范围、冲突和来源。
- 未经用户确认，不自动启用或替换 LoRA。

## 6. 研究与版本验收

### AC-13 新增官方链接

- 用户可以为新模型/LoRA登记官方链接和精确版本。
- 研究草稿区分官方、作者、社区和待验证证据。
- 关键结论保留可访问来源。
- 研究草稿在用户审核前不参与正式推荐和配方编译。

### AC-14 版本更新

- 发现新版本时生成独立档案和差异报告。
- 旧项目继续绑定旧版本，结果不被静默改变。
- 迁移预设和 LoRA 配方必须由用户确认。

### AC-15 本地验证

- 能生成无 LoRA 基线、触发词、权重和组合测试清单。
- 用户上传的代表图片可关联具体配方和测试条件。
- 官方建议、社区经验和本机结论在界面与数据中明确分开。

## 7. 项目、资产与恢复验收

### AC-16 项目重开

- 保存项目后关闭应用，再次启动可从项目库找到并打开。
- 当前版本、完整配方、结构块、指令历史和图片关联完整恢复。
- 可以从任一历史版本继续创建新版本。

### AC-17 图片资产

- 一个配方可保存一张封面图和多张补充图。
- 图片被复制到管理目录并生成缩略图。
- 同一文件重复导入时通过哈希识别，不产生无提示的重复副本。
- 浏览资产图片不会自动触发分析；只有显式“以此图为参考创作”才触发。
- 删除记录时，是否删除本地图片由用户单独选择。

### AC-18 搜索与复用

- 可通过关键词、模型、LoRA 类型、主题、人物、风格、场景、资产类型、收藏和最近使用筛选。
- 从资产复用时创建副本，不覆盖原始资产。
- 副本保留适用模型、LoRA 和参数范围。

### AC-19 备份与恢复

- 备份包含数据库、档案、研究来源、手工修订、配方和资产图片。
- 备份不包含模型/LoRA 文件和 API 密钥。
- 在干净测试目录恢复后，项目和资产可打开。
- 重新扫描模型目录后能通过哈希重建关联。
- 损坏或不完整备份必须在写入当前数据前被检测并阻止。

## 8. 离线、隐私与任务控制验收

### AC-20 离线使用

断网后仍可使用已建立档案、已登记 LoRA、本地 LLM、图片分析、中文局部修改、参数建议和资产搜索/保存。

### AC-21 外部 API 授权

- 外部调用前显示提供方和将发送的数据类型。
- 授权只对当前任务有效。
- 用户拒绝或调用失败时，不自动转发到其他外部服务。

### AC-22 长任务取消

- 图片分析和研究任务显示真实阶段状态。
- 用户取消后，后端任务停止占用推理资源。
- 已完成的部分结果可按任务类型保留，但必须标记为不完整。

## 9. 实际出图结果验收

### AC-23 一至两轮接近目标

对每个正式代表案例：

1. 固定输入、模型档案和评估用 Seed 集。
2. 由系统生成首版完整配方，用户不手改整段提示词。
3. 用户最多进行一次中文局部修改。
4. 在 Anima 中完成最多两轮手动出图。

通过条件：用户确认主体、画风和构图基本正确，核心创意没有偏离，且不是只在单个偶然 Seed 上成立。

### AC-24 稳定性

- 使用预先记录的一组 Seed 重复测试。
- 不能只展示最好的一张作为通过依据。
- 多数结果应保持同一核心主体、主要风格和构图方向。
- 如果稳定性依赖某个 LoRA、触发词或参数，必须进入配方并可追溯。

### AC-25 可复现随机词库

- 固定词库、映射、抽样器版本、`librarySeed`、抽取配置和锁定项时，跨进程重复计算
  得到完全相同的 random plan。
- 抽中项、确定性重抽、拒绝原因、软冲突和最终结构块绑定全部进入项目版本。
- 伪造词条 ID、目录版本、文件路径或超限锁定列表被服务端拒绝，random plan 不调用
  文本模型。
- 模型漏掉硬约束时最多修复一次，仍不完整则明确失败，不返回伪成功。
- 历史目录文件缺失时，已保存的最终提示词和轨迹仍可打开，只禁用重新抽取。

## 10. 不算通过的情况

- 只有页面或数据库字段，真实生成链路没有读取它。
- 前端显示已取消，但后端仍继续推理。
- 保存后刷新即丢失，或无法从项目库继续。
- 修改结果看似接近，但未点名结构块发生明显漂移。
- 推荐没有版本兼容校验、来源或理由。
- 把社区单一说法当成官方规则。
- 只用一个挑选出的幸运 Seed 证明效果。
- 依赖尚未接入的 ComfyUI 自动化才能完成主流程。
- 只生成词库 JSON、没有 sampler/轨迹/运行链路，却把“可复现随机”标为完成。

## 11. 发布门槛

第一阶段可标记为“个人可持续使用”，至少需要：

- AC-01、AC-04 至 AC-12、AC-16、AC-19 至 AC-24 全部通过。
- AC-02、AC-03 和 AC-17 通过后，图片主链路才可标记完成。
- AC-13 至 AC-15 通过后，模型/LoRA 研究能力才可标记完成。
- 对外标记“本地词库可复现随机”前必须通过 AC-25。
- 所有阻断级数据丢失、隐私泄露和静默覆盖问题清零。
- Windows 本地端到端验收记录可复查。
