# 项目总览

## 项目身份

项目名：提示词工程  
产品名：Anima Prompt Studio  
运行方式：Windows 本地优先  
目标视口：1920x1080 桌面端

当用户说“提示词工程”时，默认指本仓库与本工作台。

## 产品目标

提示词工程要解决三件事：

1. 把简短想法变成可用的 AI 绘图提示词。
2. 把图片解析成结构化提示词。
3. 把角色、画师、参考图、常用素材和作品版本沉淀成本地资产。

## 目标模块

- 文生图：全随机、拓展提示词、参考提示词。
- 图生图：本地多模型识别、拆解、合并、双语重写。
- 结构化编辑器：按人物身份、外观、服装、表情、动作、互动、场景、镜头、光影、
  风格、特效、质量和负向约束十三块编辑。
- 资源库：AnimaDex 角色、画师、本地素材、参考提示词库。
- 收藏：角色收藏和画师收藏必须分开。
- 项目库：新建、原子保存、响应丢失重放、列表、重开、版本历史、历史版本继续编辑和
  逻辑文件导出。
- 随机词库：人工原稿、可重建审查目录、固定 Seed 抽样和完整轨迹；当前仅在实验开关
  下运行，目录仍待逐条语义审核。
- 设置：本地 LLM、外部 API、视觉模型路径、模型驻留策略。

## 当前上线边界

- 项目库使用一次 `workspace/commit` 原子保存项目头和可选版本。客户端在发送前记录
  稳定操作 ID 和冻结正文；响应丢失后重放不会创建重复项目或版本。
- 每个新版本内嵌 Recipe v1，保存精确模型档案引用、十三块、正负提示词、参数及来源、
  LoRA 占位、随机计划、中文修改历史、图片/来源引用和 Recipe Hash。当前没有真实
  LoRA 档案和受管理图片，因此对应数组可以为空，不能据此宣称 LoRA/图片资产链已完成。
- 中文局部修改已支持确定性词典覆盖的指令、执行前差异、未点名块锁定、冲突/未知项
  拒绝、确认应用和追加式撤销。它不是开放式聊天或任意中文重写器；多角色卡和复杂
  依赖编辑仍未完成。
- 当前输出支持页面内预览、逐项复制和配方参数覆盖。全库/单项目逻辑 ZIP 已上线，
  可只读校验并恢复到隔离库；不包含图片、模型/LoRA 文件和密钥，也不会自动激活。
- AnimaDex 角色/画师与收藏已接入；“新建资源”和单块“保存为资源”目前只保留在
  页面会话，整组结构块“存为配方”通过 favorites API 持久化。
- 带图片、标签、备注和检索的持久参考提示词库尚未上线。
- 视觉 worker 使用仓库/环境既有路径；面向用户的视觉模型路径配置界面尚未上线。
- 词库 `sha256-counter-v1` sampler、random plan API、锁定/重抽/冲突轨迹和版本恢复已
  接入；`runtimeReady=false`、`semanticReviewRequired=true`，只有
  `PROMPT_STUDIO_EXPERIMENTAL_WORDLISTS=1` 时允许抽样。当前目录仍需人工语义审核、
  不可变版本历史和十三块原生映射，不能作为正式发布能力。
- Anima_1.1 档案已绑定版本 ID `3004063`，不注入 `safe`。checkpoint 文件、Hash 和
  已验证尺寸没有可靠本机证据，因此 `generationReady=false`；真实固定 Seed 出图仍需
  用户在外部 Anima/ComfyUI 手动验收。

## 当前原则

- 第一阶段不接 ComfyUI 出图。
- 页面先服务 1920x1080 桌面端，不做手机端。
- 所有输出提示词都保留中文和英文两个版本。
- AnimaDex 作为只读资源源，Prompt Studio 自己保存收藏、备注、版本和设置。
- 本地优先，外部 API 作为可选推理来源。
