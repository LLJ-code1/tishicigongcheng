# 项目总览

## 项目身份

项目名：提示词工程  
产品名：Anima Prompt Studio  
运行方式：Windows 本地优先  
目标视口：1920x1080 桌面端

当用户说“提示词工程”时，默认指本仓库与本工作台。

## 产品目标

提示词工程要解决三件事：

1. 把简短想法变成可用的 AI 绘图提示词。
2. 把图片解析成结构化提示词。
3. 把角色、画师、参考图、常用素材和作品版本沉淀成本地资产。

## 核心模块

- 文生图：全随机、拓展提示词、参考提示词。
- 图生图：本地多模型识别、拆解、合并、双语重写。
- 结构化编辑器：按主体、外貌、动作、场景、构图、光影、画风、负面词等块编辑。
- 资源库：AnimaDex 角色、画师、本地素材、参考提示词库。
- 收藏：角色收藏和画师收藏必须分开。
- 项目库：新建作品、版本历史、导出结果。
- 设置：本地 LLM、外部 API、视觉模型路径、模型驻留策略。

## 当前原则

- 第一阶段不接 ComfyUI 出图。
- 页面先服务 1920x1080 桌面端，不做手机端。
- 所有输出提示词都保留中文和英文两个版本。
- AnimaDex 作为只读资源源，Prompt Studio 自己保存收藏、备注、版本和设置。
- 本地优先，外部 API 作为可选推理来源。
