# 开发路线图

## 已落地

- SQLite 项目、提示词版本、资源、收藏和设置持久化。
- AnimaDex 角色、画师、搜索和缩略图的同源网关。
- 本地 LLM / 外部 OpenAI 兼容 API 配置、探测与调用。
- Anima 结构化双语输出、保真拆解、单块和多块联合再生成。
- 模型驱动全随机提示词。
- WD14、Florence、JoyCaption、Qwen3-VL 本地图片分析与部分失败保留。
- 一键启动、服务状态查询和本地模型启停。
- 提示词模块化、编译导出、原文归档和自动测试。

## 下一阶段

### 参考提示词库

- 完成参考图片、双语提示词、标签、备注和搜索的持久化界面。
- 支持把参考条目带入扩写，同时保留来源信息。

### 数据维护

- 增加 Prompt Studio 数据库备份、恢复和导出。
- 为 AnimaDex 增加导入状态、数据版本和同步时间展示。
- 明确用户素材、验证产物和可重建缓存的生命周期。

### 图片分析体验

- 为长任务提供可取消、可恢复的进度反馈。
- 减少多模型结果中的语义重复。
- 在不争抢文本模型显存的前提下提供可选 GPU 加速。

### 工程化

- 建立有效的 Git 仓库元数据与提交基线。
- 把运行状态、缓存、模型和密钥持续隔离在源码之外。
- 增加自动化的文档/API 一致性检查。
