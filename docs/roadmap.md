# 开发路线图

> 目标需求、阶段顺序与完成定义分别以
> [产品需求文档](product-requirements.md)、
> [分阶段实施计划](implementation-plan.md) 和

## 已落地

- 创意意图数据基础：版本化的 canonical session、锁定/来源/冲突 schema，以及严格的
  服务器端规范化和阶段转换。
- `POST /api/creative-intake/transition`：服务端权威的创意意图转换 API，成功转换返回
  规范会话并递增修订号。
- 原子项目元数据保存与恢复：`metadata.creativeIntake` 通过 `workspace/commit` 保存，
  可随项目重开、逻辑备份和隔离恢复；不需要 SQLite migration。
- 统一创意导演首页：文字和最多八张参考图共用一个入口，内置 Skill 生成候选方向与需求卡，所有
  状态变化继续由服务器权威转换。
- 多图本地证据与来源追溯：最多八张图、逐图八类借用用途、独立分析/重试、部分失败
  保留、稳定 `refId`、重开按缺失文件提示重附；外部文本提供商不接收原图或本地路径。
- 六组需求卡、显式确认、基础模型选择闸门和诚实的现有工作台交接；刷新和重开保持阶段。
- 高级 Skill 覆盖编辑器：内置默认只读，支持显式保存、确认恢复默认和 100,000 字符上限。
- 官网原始模型链接研究：adapter-only HTTPS 来源、逐跳 URL/DNS/redirect SSRF 校验、
  有界离线可测抓取、不可变 snapshot 和四级证据标注。
- 证据审核与档案生命周期：claim 显式批准/拒绝、人工身份补充、append-only
  draft/review 版本链、内容 Hash、CAS 激活及统一模型目录刷新；部分失败保留
  `pending_verification`，不阻塞已有模型和通用规则。
- 模型适配十三块预览：确认语义与模型表达分层、精确激活档案版本/Hash、已批准规则与
  evidence 追溯、逐块接受/英文编辑/退回、锁定事实校验、异步过期保护，以及确认后
  精确交接到工作台和 Recipe。
- LoRA-lite 档案：显式登记 HTTPS 原始链接、版本、触发词、建议权重、兼容模型、冲突
  和备注；CRUD 使用 CAS，选择写入 Recipe 快照，目录删除后历史项目与备份仍可恢复。
  不扫描或操作本地 LoRA 文件，也不做自动研究、复杂推理或自动推荐。

- SQLite schema v2、严格旧库迁移、项目/版本/收藏/设置持久化；`resources` 已承载
  LoRA-lite，其他资源类型仍预留。
- AnimaDex 角色、画师、搜索和缩略图的同源网关。
- 本地 LLM / 外部 OpenAI 兼容 API 配置、探测与调用。
- Anima 结构化双语输出、保真拆解、单块和多块联合再生成。
- 模型驱动全随机提示词。
- WD14、Florence、JoyCaption、Qwen3-VL 本地图片分析与部分失败保留。
- 一键启动、服务状态查询和本地模型启停。
- 提示词模块化、编译导出、原文归档和自动测试。
- 前端实时编译预览、块权重语法、变体对比与矩阵、版本时间线历史载入（显式保存后
  形成新版本）。
- 结构块配方（通过 favorites 持久化整组保存/带入）、画师混合器、Tag 联想补全，
  以及长任务前端停止等待（后端中断推理待做）。
- 十三块工作台与 Recipe v1：模型、双语提示词、参数及来源、LoRA 选择快照、随机轨迹、
  中文修改历史、图片/来源引用和严格 Hash 随每个版本恢复。
- Anima_1.1 模型档案绑定版本 ID `3004063`，默认 Steps 30、CFG 5.5、Euler/Euler a +
  Normal，明确不注入 `safe`；真实 checkpoint、Hash 和尺寸仍保持未验证门禁。
- AI 局部修改：读取完整十三块、自动选择必要关联块、逐块中文差异与原因、HMAC
  预览确认、失败关闭、追加式撤销和自动保存新版本。
- 可扩展出图模型选择器已接模型档案 API；当前只有 Anima_1.1。模型推荐参数可恢复，
  未验证分辨率仅作为候选，不自动推荐。
- 前端渲染统一 HTML 转义；修复 `.gitignore` 误排除 `anima.md` 的问题。
- 本地 HTTP Host/同源/HEAD/请求 framing/严格 JSON/完整图片验证加固。
- 项目、版本、收藏和设置 schema 校验，服务端版本号、稳定冲突响应与密钥不回显。
- 结构块权重入口统一为 0–120，前后端规范化去重口径一致。
- SQLite schema v2、应用标识、旧库迁移前人工故障回滚副本、损坏/未来库拒绝和并发
  幂等初始化。
- 首页项目列表、保存状态、项目重开、全部已持久化提示词版本恢复、历史版本继续编辑和
  `baseVersion` / `baseUpdatedAt` 双重过期写入保护。
- 原子 `workspace/commit`、稳定幂等键、冻结请求 journal 和响应丢失恢复；并发相同请求
  只写一个版本，幂等键正文冲突失败关闭。
- 9 类、471 条随机元素的严格编译、稳定 ID、`sha256-counter-v1` sampler、random plan
  API、锁定/重抽/冲突轨迹、Seed 前端入口和 Recipe 持久化；仅实验开关可运行，语义
  审核门禁仍保留。
- 全库/单项目逻辑 ZIP 导出、只读检查、Hash/ZIP 攻击防护和隔离恢复；不自动激活，不
  包含密钥、模型、LoRA 或图片二进制。
- Windows 干净环境 GitHub Actions workflow 已配置，覆盖 Python、Node 和生成产物
  一致性；首次线上 run 待验证。

## 下一阶段

近期从“核心代码已接通”转向“真实资产验收与发布门禁”，不把 ComfyUI 自动化作为
前置条件。

### 真实模型与词库发布门禁

- 用实际 Anima_1.1 checkpoint 记录文件身份、Hash、有效尺寸和固定 Seed 代表案例，
  完成 AC-23/24 人工出图验收后再设置 `generationReady=true`。
- 对 471 条词逐条审查允许块、兼容标签和互斥组，建立不可变目录历史并发布十三块原生
  mapping；在此之前保持 `runtimeReady=false`。
- 扩展前端抽中元素、逐项锁定、重抽、来源和冲突决策面板。

### 中文编辑完整覆盖

- 扩展 AC-05 至 AC-08 的自然语言同义表达和复杂依赖测试。
- 将多人物拆分为角色卡，并单独维护互动关系；修改一个人物时验证关系传播。

### 图片分析与 LoRA

- 将多模型图片结果整理为已确认、冲突和不确定，而不是只拼接原文。
- 在已完成 LoRA-lite 元数据和显式兼容门禁之上，后续另做本地只读扫描、文件 Hash
  重连、官网资料研究和最小组合推荐。
- 增加本地 checkpoint/Hash 与输出质量测试记录；官网链接研究、用户审核和版本差异
  已完成。

### 参考提示词库

- 将当前仅会话内可用的自建素材/单块资源接入持久化，并补齐编辑、删除和错误恢复。
- 完成参考图片、双语提示词、标签、备注和搜索的持久化界面。
- 支持把参考条目带入扩写，同时保留来源信息。

### 数据维护

- 在图片资产链建立后，把当前逻辑备份扩展到配方图片、缩略图和跨机 Hash 重连；继续
  排除模型、LoRA 文件和 API Key。
- 为 AnimaDex 增加导入状态、数据版本和同步时间展示。
- 明确用户素材、验证产物和可重建缓存的生命周期。

### 图片分析体验

- 为长任务提供可取消、可恢复的进度反馈
  （前端取消已完成；后端中断推理待做）。
- 减少多模型结果中的语义重复。
- 在不争抢文本模型显存的前提下提供可选 GPU 加速。

### 工程化

- 把运行状态、缓存、模型和密钥持续隔离在源码之外。
- 持续维护 Windows 干净环境回归，并增加自动化的文档/API 一致性检查。
