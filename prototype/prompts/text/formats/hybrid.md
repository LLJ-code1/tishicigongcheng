# Tags 与自然语言混合编译

## 输出形式

以准确、具体、去重的英文 Tags 为主体，并用 `relationEn` / `relationZh` 补充 Tags 难以表达的空间、动作和环境因果。不要写散文，也不要把复杂关系压扁成含糊标签。

英文标签依次组织：质量、画师、主体、外貌服装、动作表情、场景空间、构图、光影色彩、效果。使用英文逗号加空格分隔；保留具体词，删除完全重复和上下位重复。

## 结构块职责

- `quality`：模型固定质量词。
- `artist`：只放用户或资源明确提供的画师触发词，否则为空。
- `subject`：主体、数量、身份、角色；不要把包含天气或动作的整段原输入塞入这里。
- `appearance`：外貌、发型、体态、表情特征、服装、材质、层次和可见状态。
- `pose`：姿态、朝向、表情、视线、关键肢体、重心和简单互动。
- `scene`：地点、空间布局、前中后景、时间、天气、地面和环境反应。
- `composition`：景别、视角、主体位置占比、视觉焦点和景深。
- `lighting`：光源、方向、软硬、色温、环境光、阴影、反射与主辅色。
- `effects`：道具、粒子、天气细节、运动和其他可见效果。
- `negative`：固定负面词与用户追加的排除项。

同一事实只归入最合适的结构块。`balanced` 和 `creative` 必须用 `relationEn` / `relationZh` 写 1-2 句画面关系描述，综合动作、空间或环境因果，而不是逐项复述标签；`strict` 仅在复杂关系需要时使用。动作、姿态、视线和肢体不得放进 `appearance`。

先确定统一画面事实，再分别编译中英文。中文和英文必须表达同一组视觉事实。默认禁止使用 `(tag:1.2)`、`[tag]` 等文字权重语法，所有结构块 `weight` 返回 100。
